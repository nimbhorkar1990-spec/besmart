Dynamic Failover & Fallback Architecture

How BeSmart ensures 100% uptime for end users even during external API downtime:

Primary Tier Concurrent Dispatch

Queries are dispatched concurrently to top-priority providers (Google, Bing, Yahoo, DuckDuckGo, Brave) with isolated 3.5s timeouts.

Automated Circuit Breaker & Failover

If a primary provider returns HTTP 429, 500, or times out, it is isolated immediately. Pre-configured fallback providers (Wikipedia, Open RSS, SearXNG) seamlessly fulfill remaining slots.

Local Lucene Autonomous Buffer

Any link ever served by external engines is permanently cached and indexed into your local Apache Lucene database, ensuring zero downtime.
